## Where it is in the app

- **Settings → Support Vutidy** (⌘, then the *Help* group): the Donate card with the Ko-fi button.
- **Help → Support Vutidy** in the menu bar.

Both open the same link in your browser. Vutidy never opens it by itself and never asks twice. Other ways to help: tell someone, report a bug, or improve a translation.
